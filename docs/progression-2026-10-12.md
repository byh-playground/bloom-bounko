# 자동 부화·합성 및 시작 스테이지 검증

기준: main `60e13fc940b52ef0ad6704ec2b1cee79ea4fec87`, Edge 155.0.4283.45, 실제 Matter.js/WebGL. GameKit 실행 번들은 `159746f50e819fdc9e8e3b9df102b542f7335f6d` 고정을 유지한다.

## 변경 책임

- `pets.js`: 소유권 변경 시 자동 처리. 알 배치는 선호 종 우선·획득 ID 순서이며 전투 펫 슬롯을 교체하지 않는다. 부화 완료 후 펫 보관 → 다음 알 배치 → 모든 종 합성 순서다. 장착·잠금 재료 제외 및 종·등급별 예비 1마리는 자동 합성에 적용하며 기존 수동 합성은 유지한다. 중첩 합성은 외부 변경 콜백을 재발행하지 않는다.
- `stage-progress.js`: 스테이지별 실제 클리어 횟수와 다음 시작 선택만 저장한다. 1 기본, 2 이상은 해당 번호+1회가 조건이다. 게임의 실제 일반/보스 종료 경로가 기록을 호출하며 사망·프리뷰·중복 종료는 제외한다. 성장이나 과거 편성 스냅샷을 소유하지 않는다.
- `index.html`: 공통 Navigation에 `#/start` 화면을 연결한다. 게임 시작 → 목록 → 해금 카드 클릭 즉시 출발. 현재 성장/편성을 사용하며 추가 포인트를 지급하지 않는다. 높은 시작 지점에서도 기존 1단계 기준 면적을 생성한 후 선택 지점을 구성해 맵 크기·적 밀도 기준을 유지한다.
- 한영 UI/도움말/위키와 Pages 파일 및 SHA 메타데이터를 함께 갱신한다. 알고리즘·전투·렌더 모듈을 추가하지 않았다.
