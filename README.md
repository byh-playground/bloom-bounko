# BOUNKO · 바운코

블룸 세계관의 탑다운 2D 물리 액션 공 튕기기 게임입니다. 잔상을 보내 조준·충전하고, 타이밍에 맞춰 몸체를 돌진시켜 적과 충돌합니다. 전장을 탭해 구르며 피하고, 처치 후 지면 드롭을 자석으로 회수한 성장으로 기술과 기본 능력치를 강화합니다.

게임·스타일·도움말·상세 위키는 `index.html`, 드롭 상태와 회수 이동은 `drops.js`, 소유·편성은 `pets.js`, 공통 Unit·능력은 `abilities.js`, 종·외형은 `enemies.js`, 목표·이동 의도는 `controllers.js`, 궁극기 정의·장착·실행은 `ultimates.js`, 효과음 정의는 `audio.js`에 들어 있습니다. 현재 후보 **0.16.1**은 한국어·영어 UI/도움말/위키 전환과 저장 언어 우선 적용을 지원합니다. `i18n.js`는 공개 i18next 코어를 연결하고 `locales/ko.js`·`locales/en.js`는 표시 문구를 소유합니다. 장착 알은 110px 이상 뒤처지면 플레이어를 따라잡고 85px 안에서 원래 포메이션으로 복귀합니다. 클리어 후 회수 규칙은 그대로이며, 클리어 후 1.5초 동안 전체 지면 보상을 자석으로 끌어오고, 실제 도착분만 지급한 뒤 미회수분을 삭제합니다. 기존 처치 성장과 알은 가까이 가서 회수합니다. 자석 범위는 현재 플레이어 지름의2.5배이며 기본 대비+10%씩 투자합니다. 바깥 장착 알은 부드러운 가속·감쇠로 느슨하게 따라오고 정지하면 가볍게 떠 있습니다. 기존 공격·회피·전투 펫·알 확률·부화 조건은 유지합니다.

## 실행

저장소를 내려받아 정적 HTTP 서버로 제공합니다. Node.js가 설치된 환경에서는 다음 명령으로 실행할 수 있습니다.

```sh
git clone https://github.com/byh-playground/bloom-bounko.git
cd bloom-bounko
npx --yes http-server . -p 8000 -c-1
```

브라우저에서 `http://localhost:8000/`을 열고 **게임 시작**을 선택합니다. 외부 라이브러리의 최초 로딩에는 인터넷 연결이 필요합니다. 공개 실행: **[BOUNKO](https://byh-playground.github.io/bloom-bounko/)**.

## Rally 보스 3종 (0.16.0)

기존 꽃잎포식자·탄성갓을 남기고 데스웜·군락모함·집게사냥꾼을 추가했습니다. 같은 판의 화원 보스 방문은 꽃잎포식자→군락모함→집게사냥꾼, 동굴은 탄성갓→데스웜으로 순환합니다. 기존 3·6·9…단계 보스 흐름과 맵·성장·저장 ID는 유지합니다.

데스웜은 `Burrowable`+연사·파열을 지원하는 `ProjectileFireable`, 모함과 비행충은 `Summonable`+`Returnable`, 집게사냥꾼은 `Meleeable`+`Hookable`을 조합합니다. 능력별 ms 상태와 교체 가능한 컨트롤러를 사용하며 같은 Unit·피해·XYZ 접촉·렌더 경로가 적과 펫에 적용됩니다. 살색 이빨 입·마디, 씨앗 벌집·꽃잎 날개·출격구 4개, 갈색 몸·주황 집게와 중립 팔레트는 [Rally 원본](https://github.com/byh-playground/rally-frontier/blob/89ff07ffe87de2ff7aa293dc7117aad5992b5513/index.html)을 따릅니다. 기존 파티클 레퍼런스의 지면 링·먼지·비행 궤적 표현을 현재 제한된 burst/ringFx·곡사 표시로 연결했습니다.

잠복은 이동650ms·분출 예고420ms이며 노출3,400ms 사이에 침탄을 연사합니다. 모함·비행충의 볼륨은 지면에 닿아 본체를 공격할 수 있습니다. 비행충은 모함당 활동·도킹 합계 최대4마리, 전체 소환24마리, 수명12,000ms이고 주인 사망 때 정리합니다. 집게는 발사 직전 위치를 확정하고 실제 XY·높이 접촉에서만 피해·끌기를 적용하며 적중·빗나감 모두 회수합니다.

세 보스도 동일한10% 알·종별 무늬·등급 테두리와3,000ms 펫 부활을 사용합니다. 일반부터 데스웜 연사·모함2마리 출격·집게 근접이 유효하며, 고급은 잠복·도킹·곡사 집게, 희귀는 파열·3마리·쌍집게를 해금합니다. 모함은 전설에서4마리, 희귀 이상 능력도 위력·체력·범위로 성장합니다. 공생 비행충은 기존 소환 알5%와 독립 펫 공격을 공유합니다. 한영 도감·도움말을 함께 갱신했습니다.

## 플레이와 조작

| 입력 | 동작 |
| --- | --- |
| 화면 아래 공격 버튼 / Space / Enter | 준비 상태에서 자동 조준 잔상을 발사하고, 잔상이 진행 중이면 그 방향으로 돌진합니다. 잔상의 이동과 목표까지 남은 거리에 따라 차지가 진행됩니다. |
| W / A / S / D | 위 / 왼쪽 / 아래 / 오른쪽으로 회피 대시합니다. 방향을 함께 누르면 정규화된 대각선으로 대시합니다. 새로 누를 때 1회 실행하며 길게 눌러도 반복하지 않습니다. |
| 전장 클릭 / 탭 | 해당 방향으로 구르며 이동·회피합니다. 공격 중 구르기는 진행 중인 공격을 취소합니다. |
| 대기 | 판을 마치고 대기 화면으로 돌아갑니다. |
| 설정 | 물리 실험 설정을 엽니다. 플레이 중에는 시뮬레이션이 일시정지됩니다. |
| 대기 화면의 업그레이드 / 동행 / 도움말 / 상세 위키 | 성장 기술·능력치, 알·펫 편성과 합성, 빠른 조작 설명, 전체 게임 규칙을 확인합니다. |

게임 화면에서 WASD를 사용합니다. 메뉴·입력란과 Ctrl/Alt/Meta 조합에서는 게임 입력을 제출하지 않으며, 포커스 이탈이나 메뉴 진입 시 눌림과 대기 입력을 해제합니다. WASD와 화면 클릭은 동일한 회피 충전·쿨다운·공격 취소 규칙을 적용합니다.

새 잔상 생성은 수동·메아리·자동 연격 모두 공통 공격 탄 1발을 사용합니다. 기본 2발, 1,500ms마다 1발 순차 장전하며 HP 비용은 없습니다. 준비 탄이 80ms 정렬한 뒤 실제 생성 성공 시에만 차감하고 정렬 취소는 무료입니다. 이미 만들어진 잔상으로 수동·자동 돌진은 무료이고 회피 구르기는 별도 충전을 사용합니다. 실패한 생성은 소모하지 않습니다. 흡혈은 기본0%이며 실제 HP 피해에 투자한 비율만 회복합니다. 평상 접촉 피해는0, 명시적 공격만 피해를 주며 단계 전환은 현재 HP를 유지합니다. 돌진 피해는 공통 실제 충돌 속도 공식으로 계산합니다. 자세한 타이밍·반동·회피·보스·성장 규칙은 내장 위키를 참조합니다.

누적 처치·해금 기술·능력치 강화·알과 펫 소유권은 같은 브라우저와 같은 주소의 로컬 저장소에 보관됩니다. 진행 중인 판의 위치와 체력은 저장하지 않습니다. 저장 키 `bloom-impulse-progression-v3`는 유지하고 `{kills, defeats, unlocked, statLevels, companions:{inventory,slots,nextId}, pendingDrops:{pending}, ultimates:{slots}}`로 확장합니다. 기존 저장의 동행 필드가 없으면 빈 목록과 기본 1칸으로 시작합니다. 0.11.0의 현재 Definition에서 제거된 기술·선행 조건을 잃은 기술, 치명확률 투자 없이 남은 치명피해 투자만 제외해 포인트를 환불합니다. 누적 처치와 유효한 나머지 기술·스탯은 보존하고, 옛 기술 ID를 새 기술로 자동 변환하지 않습니다. 재선택할 자동 연격의 비용은 2 강화입니다.

## 자동 궁극기 (0.13.1)

기존 조합 강화는 연결된 기술 트리의 궁극기 해금 노드로 바뀝니다. 광채 개화(레이저) 5포인트, 포자 회오리·연쇄 가속 각 3포인트, 탄성 폭발 2포인트입니다. 기본 한 슬롯에서 시작하며 추가 슬롯은 1·2포인트로 해금하고, 로비에서 최대 세 개를 장착·해제·정렬합니다. Definition 가격 변경으로 예산을 넘는 기존 저장은 말단 기술부터 해제하고 성장·처치·동료 기록을 유지합니다.

궁극기 발동에는 포자 회오리3콤보, 연쇄 가속·탄성 폭발4콤보, 레이저5콤보와 탄약1개를 함께 소비합니다. 장착 순서의 준비된 기술부터 시전하며 재사용까지 필요한 일반 공격 충돌은 포자10회, 연쇄 가속·탄성 폭발12회, 레이저15회입니다. 대기 중인 장착 기술은 함께 충전되고 같은 공격의 중복 접촉, 벽·몸 접촉, 동료·궁극기 피해는 충전에 포함하지 않습니다. 각 기술의 비용·발동·충전·시퀀스는 데이터로 조정합니다.

레이저는 옆 이동 뒤600ms 응축하고800ms 동안 폭30px 광선을 유지하며 적을 초당120도로 추적합니다. 최단 각도차를 초당 각속도×dt로 제한하고 도달하면 초과 회전하지 않습니다. 현재 적 사망 시 다음 유효 적을 추적하며 없으면 마지막 방향을 유지합니다. 80ms 간격10회 관통 타격의 피해 예산은 공격력×1.65이며, 광선 표시와 피해 판정이 같은 빔 상태를 사용합니다. 장애물에서 끊기고 고도·거리 밖의 적에게는 닿지 않습니다. 적이 전멸해도 광선·반동·잔광·원위치 복귀를 마칩니다.

포자 회오리는 280ms 준비→880ms 나선 방출→260ms 여운, 연쇄 가속은 220ms 압축→90ms 돌진과 짧은 명중 쉼을 세 번→260ms 잔상, 탄성 폭발은 400ms 압축→420ms 확장 파동→320ms 여운입니다. 일부 단계의 짧은 감속과 연쇄 명중당 45ms·탄성 첫 명중 65ms 정지는 공통 실행 데이터로 조정합니다. 레이저 연타에는 정지가 없으며, 시간 배율을 바꿔도 타격 수·피해 예산을 늘리지 않습니다.

시전 중에만 무적이며 완료·단계 전환·로비·사망·초기화 시 정지·시간 배율·입력을 정리하고 제어를 돌려줍니다. 하단 중앙 세 슬롯에는 다음 후보, 콤보, 충전 링·남은 히트, 탄약 부족을 표시합니다. GameKit Audio·Camera·Renderer를 재사용합니다.

## 궁극기 프리뷰 (0.14.1)

기술 트리와 궁극기 편성에서 구매·장착 버튼 옆의 **프리뷰**를 누르면 미해금 궁극기도 즉시 자동 재생·반복합니다. 팝업에서 정지·재생·다시 보기·반복을 선택하고 닫기 또는 Escape로 돌아갑니다. 닫으면 기술 트리의 위치와 프리뷰 버튼 포커스가 유지됩니다.

`preview.js`는 고정 seed·적 배치·첫 tick의 준비된 궁극기 발동과 팝업 수명만 소유합니다. 팝업은 같은 게임의 별도 인스턴스에서 실제 물리·Unit·UltimateRunner·렌더·오디오를 실행하며 저장은 차단합니다. 본게임은 정지하고 체력·탄약·시간·포인트·동행·저장을 보존합니다. 다시 보기는 새 인스턴스에서 같은 60 TPS·240 tick 장면을 실행하며 임의 seek나 물리 step 배속은 없습니다.

실제 Edge에서 네 기술을 각각 두 번 실행해 위치·HP·명중·피해 결과 일치를 확인했습니다. 레이저 30회/합계495, 포자 7회/168, 연쇄 3회/345, 탄성 6회/840의 고정 배치 결과입니다. 정지·복귀·저장 보존 및 연속 열기·닫기, 반복 후 오디오 voice 0, ko/en·390px 화면을 확인했고 추가 UX 검증 PASS 7.990초·JS 오류 0입니다. 결정론 확인 범위는 동일 브라우저·고정 초기 조건입니다.

## 조합 조건 표시 (0.14.3)

## 한국어·영어 표시

상단 언어 선택은 열린 패널과 전투 중에도 사용할 수 있습니다. `bounko-language-v1`의 유효한 ko/en 설정을 우선하며, 없으면 브라우저 언어의 ko-KR/en-US 같은 지역 코드를 읽고 미지원 언어는 영어로 표시합니다. 기술/종/슬롯/저장 ID는 번역하지 않습니다. 언어 전환은 진행도·HP·공격 탄·물리 상태·패널·선택/포커스·스크롤·안내 수명을 초기화하지 않습니다. 위키 목차·검색·동적 표, 기술/능력치, 발견/알/합성, 설정/접근성 문구도 같은 언어로 갱신합니다.

i18next의 fallback·interpolation·plural과 Intl 숫자/백분율 서식을 사용합니다. 숫자 count는 원래 숫자로 전달합니다. 자체 번역 엔진이나 GameKit 신규 모듈은 추가하지 않습니다. 작성된 정적 위키/도움말 마크업만 HTML 리소스로 표시하고, 동적 값은 textContent/속성 경로로 표시합니다.

민들레 주자와 이슬 치유사는 [Rally 원본](https://github.com/byh-playground/rally-frontier/blob/89ff07ffe87de2ff7aa293dc7117aad5992b5513/index.html)의 파란 몸체·밝은 강조색·선폭을 공유합니다. 몹과 펫은 같은 종 렌더를 사용하며, 펫 등급 테두리는 몸체에만 적용해 민들레 방사선과 이슬 하이라이트를 보존합니다.

기존 한국어·영어 대표 흐름은 실제 Edge에서 PASS 12.662초·오류 0, 이번 두 종 공통 렌더 비교는 PASS 1.545초·오류 0입니다. [짧은 검증 기록](docs/verification-i18n-rally-2026-10-11.json)과 [원본·수정 전후 화면](docs/rally-two-species-comparison.png)을 참조합니다.

## 영구 동행

- 실제 등록·생성 경로의 16종(일반 기존7종·신규5종, 소환2종, 보스2종)이 대상입니다. 첫 등장 4종은 유지하고 보충 후보에 기존3종과 새5종을 포함해 알을 획득할 수 있습니다. 보스 Unit도 generic `boss`와 별도로 실제 `speciesId`를 저장합니다.
- **피해로 확정된 적 사망마다 일반·소환 5%, 실제 보스 10%를 한 번 추첨**합니다. 같은 종의 알 1개를 지면 드롭으로 남기며, 회수 때 소유권을 지급합니다. 회수 시 재추첨하지 않습니다. 이전 보스 보장 지급은 유지하지 않습니다. 자폭 완료·소환 만료·정리·동행 사망은 추첨·처치 보상이 없습니다. 피격에서 시작된 상태 피해 처치는 적중 사망으로 처리합니다.
- 기본 동행 1칸, 슬롯 강화 4회로 최대 5칸입니다. 알과 펫은 같은 칸을 사용합니다. 장착 알은 회수 여부와 무관하게 모든 적중 처치(소환 포함)에 +1, 30처치에 같은 소유 ID·종·슬롯의 Common으로 부화합니다. 예비 알은 진행하지 않습니다.
- 기존 종 Common은 준비160ms → 물리 충돌 돌진 최대520ms → 회복350ms를 사용합니다. 새5종은 Common부터 자기 기본 돌진·근접·치유 행동을 사용합니다. 피해는 공격력 × 상대 접근 속도 / 1600이며 공통 방어·반올림·남은 HP 제한을 거칩니다. Uncommon부터 원래 종 능력이 열리고 새 능력을 억지로 추가하지 않습니다.
- 동행의 HP·피해는 등급마다 ×1.8입니다. 몸체 크기는 같은 종 적의 65/72/79/86/93/100%(Common→Mythic)이며, 스킬 범위·투사체 크기의 기존 ×1.05 성장 규칙은 유지합니다. 종의 원래 몸·질량·기본 능력을 공유합니다. 플레이어 기술·스탯·에너지를 복제하지 않습니다. 피격 보호 500ms, 사망 후 복귀 **3000ms**입니다. 복귀는 새 `unitId`와 초기화된 능력을 만들며 영구 `inventoryId`는 유지합니다.

동행 표시 정책은 `petConfig.presentation` 한곳에서 실제 등급 수로 선형 정규화합니다. `companionPresentation`의 scale은 공통 `speciesConfig`에 주입되어 Matter 반지름·수직 높이와 렌더·몸 그림자·기존 선택/피격 판정에 함께 적용됩니다. 기존 등급당 ×1.05 몸체 확대는 더하지 않습니다. 종의 같은 Presentation 그림을 사용하며, 공통 `drawSpecies`가 원래 불투명 도형의 합집합 실루엣에 2.5 월드 픽셀 등급색 테두리를 입힙니다. 몸 색과 등급색의 RGB 거리가 0.16 미만이면 0.8 픽셀 중립 대비선만 안쪽에 추가합니다. 바닥 등급 원은 제거하며 아군 소환수도 소유자의 scale/outline 정책을 이어받습니다. 그림 크기에만 적용되는 별도 축소나 적/펫 역할별 그림 복제는 없습니다.

보유 카드 탭은 첫 빈칸에 장착하고 장착 슬롯 탭은 해제합니다. 빈칸이 없으면 안내만 표시하며 자동으로 교체하지 않습니다. 기본 1칸부터 최대 5칸으로 해금하고, 빈칸·잠긴 칸을 카드 슬롯으로 구별합니다. 보유 목록은 실제 소유한 펫·알만 표시하며 같은 종·종류·등급의 보유 수, 등급색, 알의 색·무늬와 30처치 부화 진척을 재사용합니다. 잠금/합성/영구 ID·저장·Roster 경로는 유지합니다.

## 발견과 효과음

미발견 알은 정체불명의 알로 표시하되 종의 성체 Presentation에서 받은 색과 무늬를 단서로 보여줍니다. 정확한 30처치 진행도와 균열·흔들림만 먼저 드러나며 첫 부화에서 짧게 모습·이름·대표 능력을 공개합니다. 발견 기록은 보유·합성 재료 소모와 독립해 저장되고, 기존 저장의 실제 보유 펫도 발견으로 인정합니다. 일반·소환 5%와 보스 10%의 적중 사망 추첨을 사용합니다. 아직 얻지 않은 종 이름·전종 개수·미발견 빈 도감 칸을 UI·위키에 노출하지 않습니다. 합성 종·등급 선택은 현재 보유한 펫만 보여 주며 부족한 재료도 3/5처럼 표시합니다. 합성 성공률과 실패 소모·장착 재료 규칙은 유지합니다.

효과음은 펫 외에도 실제 공격·방어·성장 이벤트에 연결합니다. 충돌 강도별 타격, 수동/메아리 발사·돌진·도탄·연격 시작·충전·회피, 적 공격 준비·돌진·투사체, 보스 경고·준비·부채/원형/돌진/소환, 화염·전도·포자·실제 회복, 피격·처치·사망, 레벨·기술 투자·스테이지 시작/완료, 알·첫/반복 부화·합성 결과·펫 부활과 메뉴 조작을 구분합니다. 효과음은 실제 사건에서만 요청하며 배경 입자 프레임이나 장식 렌더에는 재생을 넣지 않습니다. 소리 합성과 재생 자원은 공통 GameKit 모듈이 소유하고 BOUNKO는 소리 정의와 이벤트 연결을 소유합니다.

로비와 설정에서 전체 음량·음소거를 바꾸고 설정에서 종류별 음량도 조절합니다. 같은 종류 최소 간격과 동시 수, 전체 최대 12음 및 우선순위로 군집 충돌을 제한합니다. master 70%·headroom 24%·compressor와 종류별 음량은 초기 추천값이며 주관적 타격감의 확정 수치가 아닙니다. 실제 포인터/키 입력 뒤 context를 열고 중단 뒤 다음 입력에서 재개합니다. 잠금·음소거 때의 사건은 버리며 나중에 몰아 재생하지 않습니다. 음량·음소거는 별도 로컬 키에 저장합니다. 단독 플레이는 직접 이벤트 재생 경로를 사용하며 두 번째 rollback 기록을 만들지 않습니다.

## 이동 구르기 강화

이동 구르기는 무료이며 공통 공격 탄과 별도입니다. 신규 이동 기술 8개는 각각 **1 강화**이고 자동 연격을 선행으로 요구하지 않습니다. 모든 단계는 기본값 대비 누적 퍼센트로 계산하며 현재 값에 연속 곱하지 않습니다.

| 가지 | 해금 효과 | 선행 |
| --- | --- | --- |
| 이동 충전 I / II | 기본 충전량 +50% / 누적 +100% (2→3→4회), 증가분 즉시 지급 | 없음 / I |
| 이동 회복 I / II | 기본 충전 시간 −20% / 누적 −40% (500→400→300ms) | 없음 / I |
| 이동 거리 I / II | 기본 이동 거리 +10% / 누적 +20%, 기존 추진력·감쇠 사용, 580ms 유지 | 없음 / I; 다른 기술의 선행 아님 |
| 탄환 회피 | 기본 투사체 회피 시간 +50% (100→150ms), 몸체 접촉 피해 유지 | 이동 회복 I |
| 명중 재충전 | 실제 피해를 준 공격 대시당 최초 명중 1회, 다음 이동 충전 진행도 +20% | 이동 충전 I |

명중 보너스는 현재 1회 충전 시간을 기준으로 하므로 기본 100ms, 회복 강화 후 80ms/60ms입니다. DoT·광역 반복 피해는 중복 발동하지 않습니다. 넘친 진행도는 다음 충전에 이어지고 가득 찬 충전에는 보너스를 저장하지 않습니다. 실제 이동 거리는 관성·마찰·장애물 충돌에 영향을 받습니다. 캐릭터 아래 표시 하나를 폭 42px로 유지하며 실제 남은 충전과 다음 칸의 회복을 2~4칸으로 보여줍니다.

기존 저장 키·형식·유효 투자는 유지합니다. 새 기술의 효과는 다시 불러올 때 적용되고 재시작은 강화된 최대 충전으로 시작합니다.

## 기술과 치명타

- 「자동 연격」은 잔상 메아리 다음에 **2 강화**로 해금합니다. 수동 잔상 타이밍50% 이상 실제 명중과 다음 잔상을 만들 탄 보유가 시작 조건이며 후속 도탄·처치 추적과 조합 기술은 같은 선행 경로를 유지합니다. 새 잔상마다 공통 탄1발을 쓰고 기존 잔상으로 돌진은 무료입니다.
- 「전도 표식」은 **2,400ms** 유지되고 다음 유효 돌진 명중 피해를 **25%** 높인 뒤 한 번 소비됩니다. 같은 명중 후 새 표식을 부여할 수 있으며 중첩되지 않습니다. 「연결 방전」은 가장 가까운 다른 적 1개에 같은 표식을 전파합니다. 도탄 구매 없이도 효과를 소비하고, 도탄 우선 선택은 추가 시너지로 남습니다. 추가 피해는 공통 방어·반올림·남은 HP 제한과 한 번의 명중·회복·처치 경로를 사용합니다.
- 기본 치명피해는 **200%**, 강화는 투자당 **+6%p**이므로 1회 206%, 2회 212%입니다. 치명확률 1회 투자 뒤 치명피해 구매가 열립니다. 강화 화면과 위키는 현재 실제 최종 배율을 표시합니다.

0.11.0에서 기존 기술 29개와 반복 스탯 8종을 감사해 기술을 28개로 통합했습니다. 0.11.1 이동 가지 추가 당시 기술은36개였고, 0.12.7은 충전 성장4개 추가와 삭제10개 정리 후30개입니다. 0.12.0은 기존 반복 스탯 8종에 동행 슬롯 투자 1종을 더합니다. 동행 슬롯만 4회 상한을 두며 기존 반복 스탯의 구매 규칙·관통 통합은 변경하지 않습니다.

## 스테이지 진행

보스는 **3·6·9…단계**의 일반 처치 목표 뒤에만 나옵니다. 나머지 단계는 목표 달성으로 바로 clear합니다. 목표는 기존 `7 + 4 × (단계 - 1)`이며 clear 뒤1,500ms 전환과 공격/연격/구르기 상태 초기화를 사용합니다. 현재HP와 공격 탄의 충전 진행은 단계 전환에 유지됩니다. 남은 적·탄막은 clear 즉시 정리하며 전환 중 자석 범위만 맵 전체로 넓힙니다. 실제 몸에 도착한 지면 보상만 지급하고, 시간 종료 시 미회수 드롭과 저장 목록을 비운 뒤 다음 단계로 넘어갑니다. 일반·소환·실제 보스의 기존 알 추첨 확률은 유지하며 회수 때 지급합니다. 적 외형·능력·개별 스탯·성장 경제·펫은 기존 단계 규칙을 사용합니다.

맵 구간은 **1~3 → 4~6 → 7~9…**입니다. `mapTier = floor((단계 - 1) / 3)`, `radius = min(1600, 550 × (1 + 0.22 × sqrt(mapTier)))`이며 첫 보스 뒤 4단계 반경은 550→671입니다. 같은 구간은 반경·테마·지형 seed를 유지합니다. 웨이브 배치는 단계별 seed를 사용합니다. 균사 동굴의 기존 4단계 첫 해금은 유지하고 4~6 테마를 보존해 **6단계 버섯왕**으로 연결합니다. 이후 신규 테마도 확장 구간 시작(1·4·7…)을 unlockStage로 등록합니다.

동시 적은 첫 맵에서 정확히 **4마리**입니다. 그 뒤 Config의 `initialPopulation=4`, `populationPerStage=1`, `maxEnemies=82`로 `round((4 + 단계 - 1) × 현재 플레이 면적 / 첫 플레이 면적)`을 계산합니다. 구간 경계의 랜덤 다각형 때문에 계산값이 줄지 않도록 이전 목표 +1을 하한으로 삼으며 최대 82를 적용합니다. 보충도 같은 동시 생존 목표를 따릅니다. 처치 목표와 동시 생존 수는 별도입니다.

매 단계 시작에 중앙 **STAGE 번호**를 1,100ms 표시하고 사라지게 합니다. 배너는 pointer-events:none이며 입력과 게임 틱을 막지 않습니다. 단계 번호·보스 예고는 하나의 배너를 사용하고 보스 예고가 우선하며, 이전 clear 중앙 문구는 제거했습니다. 기존 stageStart/stageClear 효과음을 사용합니다.

## Pages 정적 배포

[Pages workflow](.github/workflows/pages.yml)는 main 변경과 수동 실행에서 검증한 HTML을 정적 파일로 게시합니다. 한 job에서 checkout → Pages 설정 → 파일 준비 → artifact 업로드 → 배포를 수행합니다. 별도 게임 빌드나 테스트 매트릭스는 추가하지 않습니다.

배포 파일은 index.html, pets.js, audio.js, abilities.js, drops.js, enemies.js, controllers.js, i18n.js, locales/ko.js, locales/en.js, build.json, .nojekyll입니다. HTML은 저장소의 바이트를 그대로 사용하며, [build.json](https://byh-playground.github.io/bloom-bounko/build.json)에 배포 커밋·UTC 빌드 시각·게임 버전·BUILD_ID·모든 게임/번역 파일 SHA-256 및 i18next 버전·ESM SHA-256과 고정 오디오 SDK 커밋·SHA-256을 자동으로 기록합니다. HTML의 BUILD_ID는 검증한 게임 원본을, build.json의 commit은 그 파일을 게시한 커밋을 식별합니다. 배포 상태는 저장소의 Actions에서 확인합니다.

GitHub Pages의 게시 소스는 Settings → Pages → Build and deployment → GitHub Actions입니다. 정적 파일 게시가 성공한 뒤에도 실제 공개 주소의 라이브러리 로딩과 부팅을 별도로 확인합니다.

[enemies.js](enemies.js)는 실제 클래스 조합과 스펙·원본 도형 렌더를 소유하고 [abilities.js](abilities.js)는 다른 유닛/펫 호스트에도 사용할 수 있는 subclass factory 능력과 공통 좌표·궤적·충돌 함수를 제공합니다. 공개 문법은 최신 개발 규칙의 `mixin(BaseClass, ...Mixins)`와 `mixin(...Mixins)` 두 가지이며 함수 identity로 중복 적용을 막습니다. 클래스 정의 때 조합하고 생성 때 상태를 만들며 프레임마다 조합 객체를 만들지 않습니다. Host가 소유한 몸체·스탯·위치 데이터(HAS-A)를 능력 내부에 복제하지 않습니다. 이 릴리스는 실제 신규 펫 행동을 추가하지 않습니다.

재사용 Host 계약은 `Unit({id,type,body,config,adapter})`이며 body는 Matter 원형 몸체와 plugin, config는 hp/radius/height 및 해당 능력 namespace, adapter는 지형 검사·이동·추적·공격/표현 연결을 제공합니다. 능력은 자신의 namespace와 행동을 직접 소유하며 update/onHit/cancel의 의도적인 override는 super로 연결합니다. `groundArc/stepArc`는 순수 x/y 지면 + z 높이 궤적 데이터로 도약과 곡사에 같이 쓰입니다. 공통 루프에는 유닛 ID별 특수 상태 분기가 없습니다.

몸체는 발밑 `feetZ → feetZ + height` 부피입니다. 플레이어 32, 벼룩 30, 콩벌레·가시열매 38, 봉선화 42이며 기존 적·펫·일반 탄은 실제 반지름의 2배, 잔상은 14입니다. `body.plugin.volume`이 단일 권위 데이터입니다. `snapshotVolumes`는 틱 시작을 저장하고 `sweepVerticalContacts`는 solver 전에 원래 적분 끝점을 보존합니다. `contactWindow`가 XY 접촉과 수직 겹침의 시간 구간을 교차하므로 각각 다른 시점의 겹침을 합쳐 유령 타격을 만들지 않습니다. Matter 0.20.0의 Detector 결과를 Pairs/solver 전에 걸러 물리와 피해가 동일한 높이 규칙을 쓰며, 하강하면 지면에 닿기 전에도 접촉하고 기존 XY 겹침에서 재진입해도 collisionStart가 발생합니다. 수직 mover의 한 틱 통과는 beforeSolve에서 보완하고 기존 돌진의 swept 피해 보완도 같은 함수를 씁니다. Matter 원 몸체의 다각형 근사와 SAT 접점을 맞추는 보정은 Config `spatial.sweep.insetPx=1`이며 유효 XY/Z 접촉 구간을 넘지 않습니다. 정적 벽·장애물은 통과할 수 없는 지면 장벽으로 취급합니다.

벼룩은 320ms 예고·650ms 도약·높이90·2200ms 재사용 대기입니다. **별도 착지 피해/AOE는 없고** 기존 접촉 피해 경로만 씁니다. 콩벌레는 1000ms 예고 중 처치하면 자폭 취소, 살아서 완료할 때만 반경96 폭발합니다. 가시열매는 550ms 준비·450ms 활성·1500ms 회복이며 활성 시작에 8개 방사 가시, 활성 중 살아남은 직접 타격에 창당 한 번 반격합니다. 준비/회복에도 공격 가능하고 상시 반사하지 않습니다. 봉선화는 490ms 예고 뒤 150ms 간격의 4발, 높이88/96/100/92 곡사입니다. 목표는 발사 시 고정하며 비행 중 몸체 겹침으로 폭발하지 않고 950ms의 시뮬레이션 비행 뒤 고정 착탄에서 한 번 폭발합니다. 곡사탄은 일반 탄의 global-time 수명 검사에서 제외하며 비행 완료/경로 차단/단계 종료만으로 종료하므로 히트스톱·SHADOW 감속 중 조기 소멸하지 않습니다. 도약/곡사의 경로·목적지는 경계와 장애물을 검사합니다. 현재 x/y 그림자와 고정 목적지/착탄 표식은 별개이고 렌더는 y-z로 투영합니다.
