# 테마 단위 시작 선택 및 보스 격파 해금

v0.21.0의 개별 스테이지 선택을 사용자 의도에 맞게 테마 단위로 교체한다. 해금 기준은 최신 확정인 **현재 테마의 정상 보스 격파**이며, 테마 전체 구간 완료나 별도 최종 보스 조건은 추가하지 않는다.

## 실제 콘텐츠 매핑

| 테마 ID | 최초 시작 | 최초 구간 | 해금 보스 격파 |
|---|---:|---|---:|
| garden | 1 | 1–3 | 항상 이용 |
| cave | 4 | 4–6 | 3회 |
| frostGarden | 7 | 7–9 | 4회 |
| acidMarsh | 10 | 10–12 | 5회 |

이는 THEME_POOL.unlockStage와 C.stage.mapEvery(현재 3), mapStartAtStage, themeForStage를 확인한 결과다. 최초 테마 배정 이후 13/16/19… 구간은 기존 가중 선택으로 앞선 테마를 재사용한다. 반복 구간을 새로운 테마 카드로 만들지 않는다. 동일 보스 종이 동굴/서리 정원 등에 공유되므로 보스 종 ID로 집계하지 않고 전투 중 stage.themeId에만 기록한다. 모든 정상 테마 보스가 대상이며 특정 최종 보스만 요구하지 않는다.

## 저장과 책임

theme-progress.js는 현재 테마 정의를 입력받아 ID별 bossDefeats, 방문 여부, 선택 테마만 저장한다. 정렬된 정의의 첫 항목은 항상 이용 가능하며 추가 항목은 3/4/5…회다. 시작 위치는 해당 정의의 unlockStage를 그대로 사용한다. 게임의 적 사망 정책에서 실제 stage.boss 객체를 확인한 뒤, PLAYING/생존/비프리뷰 조건과 hit 사망·wild·비소환·BOSS 단계 조건을 검증한다. 이미 기록한 보스 객체는 WeakSet으로 중복 제외한다. 일반 웨이브 클리어는 집계하지 않는다.

이전 stage-progress.js, 개별 스테이지 카드/페이지 제어, stageStart 번역/배포 파일/저장 경로를 제거했다. 기존 stageProgress는 읽거나 변환하지 않는다. 따라서 잘못된 이전 횟수와 시작 선택은 테마 해금을 부여하지 않으며, 새 themeProgress는 기본 화원에서 시작한다. 성장·포인트·장착·소유 펫·자동 설정·스킬·대기 드롭 등 나머지 저장 데이터는 기존 로더로 유지한다. 호환 분기나 전체 저장 초기화는 없다. 의미가 다른 진행 저장으로 교체하므로 공통 관리 규칙의 비호환 MINOR에 따라 0.22.0으로 올렸다.

## 실제 검증

[Edge 결과](verification-theme-start-2026-10-12.json), [모바일](theme-start-390.png), [PC](theme-start-1280.png).

- 실제 Matter/WebGL 경로에서 일반 적 처치 → 보스 출현 → 보스 사망으로 테마별 해금 횟수 검증. 중복 사망 콜백은 1회만 집계. 일반 적/웨이브 클리어 및 플레이어 사망은 제외.
- 동일 보스 풀을 사용하는 cave/frostGarden이 별도 집계되며 15단계 반복 acidMarsh의 보스는 acidMarsh만 증가한다.
- 네 테마 카드를 선택해 각각 1/4/7/10 및 해당 themeId로 시작하는지 확인. 성장·장착·자동 설정 스냅샷 동일.
- 잘못된 옛 스테이지 횟수 1,000회가 있어도 추가 테마 0회/잠김으로 시작. 갱신 저장에는 옛 stageProgress가 없고 다른 성장 데이터는 보존.
- 390×568 / 1280×844 카드 목록, 잠금 횟수, 최근 선택, 한영 전환, 직접 URL/F5/뒤/앞 이동, 저장 복원, 프리뷰 저장 격리 및 JS 오류 0 확인. 180초 상한 이내.
- 프리뷰 인스턴스에도 일반 처치 → 보스 생성 → 보스 처치 경로를 주입해 본게임 저장 바이트 불변을 확인했다. 최종 기능 검사 3.69초.
- 기존 GameKit 실제 소비 검사도 시작 카드 선택자만 갱신해 11.8초 통과했다. PC/모바일 Navigation·프리뷰 정지/재시작·소개·저장 바이트 불변·전투 중 설정 복귀를 유지한다.

전투 계산·렌더링·부화/합성 알고리즘은 수정하지 않았다. 이번 수정의 CPU/GPU 성능 재측정과 실제 Android/Safari/Firefox는 미검증이다.
