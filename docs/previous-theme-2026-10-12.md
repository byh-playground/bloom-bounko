# 직전 테마 보스 기준 해금 수정 — 0.22.1

테마 자체 보스 횟수를 보던 v0.22.0의 해금 조회를 직전 테마로 수정했다. 카드 문구만 바꾸지 않고 ThemeProgress.unlocked가 최초 시작 순서의 predecessor 카운터를 읽도록 변경했다.

| 시작할 테마 | 실제 조회하는 조건 |
|---|---|
| 화원 | 항상 이용 |
| 균사 동굴 | 화원 보스 격파 3회 |
| 서리 정원 | 균사 동굴 보스 격파 4회 |
| 산성 늪지 | 서리 정원 보스 격파 5회 |

카드는 한국어/영어 모두 선행 테마의 이름과 현재 횟수를 표시한다. 해금된 미방문 테마도 목적지 이름을 표시한다. 시작 위치 1/4/7/10과 성장·편성·자동 부화/합성은 유지한다.

## 저장

themeProgress의 기존 ID별 bossDefeats를 사실 그대로 읽고 저장한다. 처치 이벤트는 실제 현재 테마만 증가시키며 다른 테마로 이관·가산하거나 재귀 해금하지 않는다. 저장 스키마·처치 이벤트 코드·SDK 핀은 바꾸지 않았다. 기존 선택이 수정된 해금 조건을 만족하지 않으면 기존 로더의 선택 검증에 따라 기본 화원으로 돌아가며 횟수와 다른 성장 데이터는 유지한다.

## 실제 검증

[Edge 결과](verification-previous-theme-2026-10-12.json), [모바일](previous-theme-390.png), [PC](previous-theme-1280.png).

- 기존 저장의 화원/동굴/서리/늪 보스 횟수 2/3/4/90을 그대로 복원. 대상 자체 횟수는 종전 기준을 충족하지만 선행 횟수가 부족하므로 세 추가 테마 모두 잠김.
- 실제 적 처치 → 보스 생성 → 보스 사망으로 검사. 늪 보스 처치로 늪 카운터만 91이 되고 앞선 테마나 자신이 해금되지 않음. 동굴 보스 처치는 동굴 4회를 만들어 서리만 해금하며 동굴 자신은 계속 잠김. 화원 3회로 동굴, 서리 5회로 늪이 각각 해금됨.
- 중복 사망 콜백은 추가 집계하지 않으며 최종 저장은 3/4/5/91. 횟수 이관/가산 없음.
- 한영 카드가 각각 `화원 보스 격파 2 / 3회` / `Garden boss defeats 2 / 3`처럼 실제 선행 횟수를 표시. PC/모바일 에뮬레이션, 새로고침, 최근 선택, 해금 카드 선택 후 4/7/10 시작, 성장·장착·자동 설정 스냅샷 불변 확인.
- 기존 GameKit consumer 10.4초 통과: PC/모바일 Navigation·프리뷰·소개·저장 바이트 불변·전투 설정 복귀. JS 오류 0, 180초 상한 이내.

실제 Android 기기·Safari·Firefox 및 CPU/GPU 성능 재측정은 이번 수정에서 수행하지 않았다.
